# Convenciones de código

- **Python 3.10+**, `from __future__ import annotations` en módulos nuevos del harness.
- **Tipado** explícito en APIs públicas del paquete `harness/`.
- **UTF-8** para todos los Markdown y JSON del repo.
- **Nombres de feature** en `feature_list.json`: `name` en `snake_case`, estable para nombres de archivo `impl_` / `review_`.
- **Commits** (humanos): mensajes descriptivos; un ciclo del harness puede corresponder a una o varias features según tu flujo Git.
